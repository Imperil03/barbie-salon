# Direct Insight · аналитический дашборд

Шаблон проектирования и сборки **одностраничного интерактивного отчёта** на чистом HTML/CSS/JS.
Использовать как методологический эталон для аналогичных проектов: маркетинг-аналитика, SEO,
сравнение кампаний, отчёт-презентация для клиента.

---

## Технологический стек

- **HTML/CSS/JS** в одном файле, без бандлеров
- **ECharts 5.5** через CDN — все интерактивные графики
- **Inter** через Google Fonts CDN — единственный шрифт, веса 400/500/600/700
- **Inline SVG** для иконок (Lucide-style, stroke-width 1.75) — никаких эмодзи
- **Inline favicon** через `data:image/svg+xml` (фирменный знак)
- **localStorage + URL hash** для tab persistence — без cookies/бэкенда

## Дизайн-система

### Цветовая палитра (CSS variables)

| Группа | Токены | Назначение |
|---|---|---|
| Surface | `--bg`, `--surface`, `--surface-2`, `--border` | Фоны и разделители |
| Text | `--text`, `--text-2`, `--text-3`, `--text-4` | 4 уровня иерархии текста |
| Brand | `--primary` (#7C5CFF), `--primary-soft`, `--primary-wash` | Фирменный фиолетовый |
| Semantic | `--good` (зелёный), `--bad` (красный), `--warn` (амбер) | Статусы |
| Period | `--c-pink` (P1/«до»), `--c-blue` (P2/«после»), `--c-violet` | Сравнение «до/после» |
| Campaign | `--c-barbie`, `--c-spalnya` (бирюзовый) | Идентификация кампании |

**Правило:** не использовать сырые hex в компонентах — только токены.

### Радиусы и тени (масштаб)

`--radius-md: 12px`, `--radius-lg: 16px`, `--radius-xl: 20px`
`--shadow-sm`, `--shadow-md`, `--shadow-lg` — три уровня elevation.

### Типографика — fluid scaling через `clamp()`

| Элемент | clamp() | Назначение |
|---|---|---|
| H1 | `clamp(22px, 4.5vw, 28px)` | Заголовок страницы/вкладки |
| KPI value | `clamp(24px, 5vw, 30px)` | Главное число карточки |
| Section title | `clamp(16px, 3.5vw, 18px)` | Заголовок секции |
| Body | 14px (фикс) | Основной текст |

Шкала шрифтов: 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 16 / 18 / 22+
Веса: 400 (body), 500 (label/medium), 600 (subhead/strong), 700 (heading)
Числа с `font-feature-settings: "tnum"` — табулярные цифры для выравнивания в столбцы.

### Spacing (отступы)

Кратно 4: 4 / 8 / 10 / 12 / 14 / 16 / 18 / 20 / 22 / 24 / 32 / 48
Контейнеры через `clamp()` для адаптивности:
- `.page` padding-x — `clamp(14px, 4vw, 32px)`
- `.card` padding — `clamp(16px, 3vw, 22px)`

## Адаптивная вёрстка (mobile-first 2026)

**Принципы:**
1. **Mobile-first**: дефолтные стили — для телефона, breakpoint'ы наращивают сложность
2. **Fluid scaling** через `clamp()` — основной механизм; @media только для перестановок
3. **Touch targets ≥ 44px** на всех интерактивных элементах (кнопки, табы, чипы)
4. **2 ключевых breakpoint'а:** 768px (планшет/landscape) и 480px (маленькие телефоны)
5. **Внутренние сетки** используют `repeat(auto-fit, minmax())` или конкретные правила

**Mobile-specific сокращения:**
- Topbar: скрываются вторичные подписи бренда и иконки в pill
- Tab nav: скрывается meta-подпись («Красноярск · апрель»)
- Period pill: на телефоне (≤ 480px) скрывается полностью
- Card padding уменьшается на 4-6px
- Чарты `clamp(220px, 32vw, 260px)` — мини, `clamp(260px, 40vw, 340px)` — большие
- Tabs прокручиваются горизонтально с `scroll-snap-type: x proximity`

**Тестировать обязательно на:** 375px iPhone SE, 412px Android, 768px iPad portrait.

## Сторителлинг и UX

### Принципы графиков

1. **«Вопрос → ответ»** — заголовок карточки задаёт вопрос, подзаголовок отвечает цифрой
   *Плохо:* «CPC по дням» · *Хорошо:* «Цена клика — главный выигрыш / 7 апр платили 1 102 ₽, 8 апр — уже 595 ₽»
2. **Аннотации граничных точек** на line-чартах — markPoint с реальными значениями в момент перехода
3. **Линии средних/медиан** — пунктиром на всех trend-чартах, с подписью `ø` (среднее) или `мед` (медиана)
4. **CPC и подобные «ценовые» метрики** — взвешенное среднее (`Σ расход / Σ клики`)
5. **Объёмные счётчики** (расход/клики/показы) в типичный день — медиана + min/med/max footer
6. **Маркеры событий** — вертикальные пунктиры с подписью даты для смен стратегии, стартов работ
7. **Цветовая семантика всегда согласована с текстом** — если описание говорит «ожидаемо», цвет должен быть нейтральным (не warning жёлтым)
8. **Tooltips** — кастомные форматтеры с локализацией (`Intl.NumberFormat('ru-RU')`)

### Insight banner (главный вывод)

- Один фиолетовый прямоугольник в начале вкладки
- 1-2 предложения, заканчивается рекомендацией («Рекомендуем оставить ручное управление»)
- Числа в `<b>`, позитивные дельты в `<span class="pos">` (зелёный)
- Иконка слева — лампочка/график/звезда — конкретно к смыслу

### Caveat (жёлтая оговорка)

- Используется когда выводы основаны на неполных данных (нет CR/CPL из Метрики)
- Маркетинговая честность важнее эффектности

### KPI карточки

- Структура: `[label + delta-pill]` → `[value + unit]` → `[sub-text «было X · экономия Y»]` → `[sparkline]`
- Стрелки delta: `↗` для положительных дельт, `↘` для отрицательных — направление = знак числа, цвет = «хорошо/плохо»
- Sparkline отдельным рядом снизу (не за value), height 32px, никогда не перекрывает текст

### Tag colors (card-tag)

| Тип | Цвет | Когда |
|---|---|---|
| `good` | Зелёный | Чисто положительный результат |
| `info` | Фиолетовый | Нейтральный side-effect, ожидаемый трейд-офф |
| `warn` | Амбер | Реальное предупреждение, требует внимания |
| `bad` | Красный | Аномалия / проблема |
| `teal` | Бирюзовый | Идентификация Спальни/контроля |

## UI-элементы и их обязательная функциональность

**Никаких декоративных интерактивных элементов** — каждая кнопка / чип / таб должны что-то делать:
- Search input → удалить, если нет логики поиска
- Filter chips → удалить, если данные предзаписаны
- «Создать», «Сравнить» → удалить, если нет действия
- Three-dot menu → удалить, если нет drill-down
- Hover state на header таблицы → удалить, если сортировка не работает

**Что точно функционально:**
- Tabs (переключение + сохранение состояния)
- Print button → `window.print()` + print-стили
- Внешние ссылки (статьи, доноры) → реальные URL в `target="_blank"`
- Tooltip графиков (наведение)

## Tab persistence

Активная вкладка сохраняется через **2 механизма:**

1. **URL hash** (`#strategy`, `#compare`, `#kaliningrad`, `#seo`)
   - Обновляется через `history.replaceState` при клике
   - Слушаем `hashchange` для поддержки back/forward браузера
   - Делает URL **shareable** — клиент может прислать ссылку на конкретную вкладку

2. **localStorage** (`di-active-tab`)
   - Бэкап на случай перезагрузки без хеша
   - Try/catch на случай блокировки (приватный режим)

**Приоритет инициализации:** URL hash → localStorage → дефолт (`strategy`).

## Accessibility (минимум)

- `aria-label` на иконочных кнопках и графиках
- `aria-selected` на табах
- `aria-hidden="true"` на декоративных SVG
- `role="region"` на смысловых блоках (insight banner)
- Touch targets ≥ 44px
- Контрасты текста ≥ 4.5:1 (проверить тёмный текст на светлой подложке)
- `:focus-visible` outline на интерактивных элементах
- `loading="lazy"` на изображениях ниже фолда
- Семантические `<header>`, `<section>`, `<nav>`, `<footer>`

## Lazy-init вкладок

Чарты ECharts инициализируются **только при первом открытии** вкладки (паттерн `initialized[name] = true`). При повторном переключении — `chart.resize()` через `requestAnimationFrame`. Это:
- Ускоряет первую загрузку
- Корректно считает размеры (ECharts не любит инициализацию в `display: none`)

---

## Print

`window.print()` доступен через кнопку «Печать» в topbar.
Print-стили скрывают topbar и tab-nav, выводят **все вкладки последовательно** с `page-break-before: always`.
Карточки получают `box-shadow: none` и `break-inside: avoid` чтобы не разрезались.

## Антипаттерны (что НЕ делать)

1. **Inter в проекте, который требует «creative direction»** — но для clean SaaS-аналитики Inter оправдан. Контекст важен.
2. **Фиолетовые градиенты на белом** — клише AI-дизайна; используем умеренно, как акцент в banner'ах
3. **Эмодзи как иконки** — ломаются между ОС, не управляются токенами
4. **Декоративные кнопки без функций** — путают пользователя
5. **Sparkline за текстом** — нечитаемо; всегда отдельным рядом
6. **Цвет как единственный носитель смысла** — добавлять иконку/текст
7. **Простое среднее как «типичный день»** для счётчиков — медиана надёжнее (устойчива к выбросам)
8. **«CTR упал на 9 п.п.» в warning-цвете** если в подзаголовке написано «ожидаемо» — цвет должен соответствовать смыслу
9. **Hardcoded breakpoints для каждой компоненты** — консолидировать в 2-3 main breakpoint'а + clamp() для остального

1. **Барби · смена стратегии 8 апреля оправдана** — расход −50%, клики +42%, охват +106%, CPC 821 → 290 ₽. Рекомендуем оставить ручное управление.

4. **SEO · barbie-salon.ru (первый месяц)** — поисковый трафик +23% к мартовскому среднему, 84% ключей в топ-10 Яндекса (было 46%). 5 новых тематических групп — с 0 до 55-100% в топ-10 за месяц благодаря 7 SEO-статьям.
